# Appace — Implementation Plan

> "Earn screen time as hours pass. Save it up, spend it when you want."

## Project Overview

An Android app (React Native + Expo + Kotlin native module) that:
- Has a configurable **daily active window** (default 6am–midnight)
- Grants a **opening balance** (default 5 mins) at the start of the window each day
- Accrues a configurable amount of screen time **on the hour, every hour** within the window (e.g. 5 mins drops at 7am, 8am, 9am... 11pm)
- **No notifications** for accruals — time appears silently, no dopamine ping
- Balance **resets to zero at end of window** (midnight) — unused time does not carry over
- Outside the window, no accrual happens and tracked apps are unrestricted
- When a tracked app is opened and balance is zero **during the window**, a "Time's Up" overlay is shown
- If a session is in progress at midnight, that session is allowed to finish — reset applies to the next open
- Uses an Accessibility Service (Kotlin) for app detection — event-driven, not polling
- Uses WorkManager (Kotlin) for scheduled accrual — battery-conscious, doze-safe, silent

### 3a. BalanceEntity + BalanceDao + AppDatabase (Room)

```kotlin
// BalanceEntity.kt
@Entity(tableName = "balance")
data class BalanceEntity(
    @PrimaryKey val id: Int = 1,
    val balanceSeconds: Long,             // current balance in seconds
    val windowStartHour: Int,             // e.g. 6 for 6am
    val windowEndHour: Int,               // e.g. 24 for midnight
    val openingBalanceSeconds: Long,      // granted at window open each day (e.g. 300 = 5 mins)
    val hourlyAccrualSeconds: Long,       // added silently each hour on the hour (e.g. 300 = 5 mins)
    val lastAccrualHour: Int,             // last clock-hour that was accrued (prevents double-fire)
    val lastResetDate: String,            // "YYYY-MM-DD" — tracks which day the last reset happened
    val windowOpenGrantedToday: Boolean   // whether opening balance has been granted today
)
```

```kotlin
// BalanceDao.kt
@Dao
interface BalanceDao {
    @Query("SELECT * FROM balance WHERE id = 1")
    fun getBalance(): BalanceEntity?

    @Insert(onConflict = OnConflictStrategy.REPLACE)
    fun upsert(balance: BalanceEntity)
}
```

- Use a **singleton** `AppDatabase` instance
- All DB reads/writes happen on a background thread (use Kotlin coroutines with `Dispatchers.IO`)

### 3b. BalanceRepository

```kotlin
// BalanceRepository.kt
class BalanceRepository(context: Context) {
    private val dao = AppDatabase.getInstance(context).balanceDao()

    fun getBalance(): BalanceEntity { ... }
    fun deductSeconds(seconds: Long) { ... }    // called when user exits tracked app
    fun hasTimeRemaining(): Boolean { ... }
    fun isWithinWindow(): Boolean { ... }       // is current time inside active window?
    fun tick() { ... }                          // called by WorkManager every 15 mins — handles all logic
    fun setWindowHours(start: Int, end: Int) { ... }
    fun setOpeningBalance(minutes: Int) { ... }
    fun setHourlyAccrual(minutes: Int) { ... }
}
```

The entire daily logic lives in `tick()`, called by WorkManager every 15 minutes:
```kotlin
fun tick() {
    val now = LocalDateTime.now()
    val current = getBalance()
    val todayStr = now.toLocalDate().toString()
    val currentHour = now.hour

    // 1. RESET — if it's a new day and we're past window end, wipe balance
    if (todayStr != current.lastResetDate && currentHour >= current.windowEndHour % 24) {
        dao.upsert(current.copy(
            balanceSeconds = 0,
            lastResetDate = todayStr,
            windowOpenGrantedToday = false,
            lastAccrualHour = -1
        ))
        return
    }

    // 2. Outside window — do nothing
    if (!isWithinWindow()) return

    // 3. OPENING BALANCE — grant at window start if not yet granted today
    if (!current.windowOpenGrantedToday) {
        dao.upsert(current.copy(
            balanceSeconds = current.balanceSeconds + current.openingBalanceSeconds,
            windowOpenGrantedToday = true,
            lastAccrualHour = current.windowStartHour
        ))
        return
    }

    // 4. HOURLY ACCRUAL — grant if we've crossed into a new hour since last accrual
    if (currentHour > current.lastAccrualHour && currentHour < current.windowEndHour) {
        dao.upsert(current.copy(
            balanceSeconds = current.balanceSeconds + current.hourlyAccrualSeconds,
            lastAccrualHour = currentHour
        ))
        // No notification — silent drop
    }
}
```

> `lastAccrualHour` prevents double-firing if WorkManager runs twice in the same hour. `lastResetDate` ensures the reset only happens once per day.

### 3c. AccrualWorker (WorkManager)

```kotlin
// AccrualWorker.kt
class AccrualWorker(context: Context, params: WorkerParameters)
    : CoroutineWorker(context, params) {

    override suspend fun doWork(): Result {
        return withContext(Dispatchers.IO) {
            try {
                BalanceRepository(applicationContext).accrueHour()
                Result.success()
            } catch (e: Exception) {
                Result.retry()
            }
        }
    }
}
```

```kotlin
// AccrualWorker.kt
class AccrualWorker(context: Context, params: WorkerParameters)
    : CoroutineWorker(context, params) {

    override suspend fun doWork(): Result {
        return withContext(Dispatchers.IO) {
            try {
                BalanceRepository(applicationContext).tick()
                Result.success()
            } catch (e: Exception) {
                Result.retry()
            }
        }
    }
}
```

Schedule at 15-minute intervals — the minimum WorkManager allows. `tick()` is idempotent so firing multiple times per hour is harmless:
```kotlin
val request = PeriodicWorkRequestBuilder<AccrualWorker>(15, TimeUnit.MINUTES)
    .setConstraints(Constraints.Builder()
        .setRequiresBatteryNotLow(false)
        .build())
    .build()

WorkManager.getInstance(context).enqueueUniquePeriodicWork(
    "appace_tick",
    ExistingPeriodicWorkPolicy.KEEP,
    request
)
```

> WorkManager fires every 15 minutes, but `tick()` checks `lastAccrualHour` before awarding anything — so even if it fires 4 times in one hour, the user only gets one accrual. No notification is sent for any accrual.

### 3d. AppWatcherService (Accessibility Service)

```kotlin
// AppWatcherService.kt
class AppWatcherService : AccessibilityService() {
    private val repo by lazy { BalanceRepository(this) }
    private var currentTrackedApp: String? = null
    private var usageStartTime: Long = 0

    override fun onAccessibilityEvent(event: AccessibilityEvent) {
        if (event.eventType != AccessibilityEvent.TYPE_WINDOW_STATE_CHANGED) return
        val packageName = event.packageName?.toString() ?: return

        val trackedApps = getTrackedApps()   // read from SharedPreferences

        if (packageName in trackedApps) {
            // A tracked app just came to foreground
            if (!repo.hasTimeRemaining()) {
                launchTimesUpScreen()
            } else {
                currentTrackedApp = packageName
                usageStartTime = System.currentTimeMillis()
            }
        } else {
            // User left a tracked app
            if (currentTrackedApp != null) {
                val secondsUsed = (System.currentTimeMillis() - usageStartTime) / 1000
                repo.deductSeconds(secondsUsed)
                currentTrackedApp = null
            }
        }
    }

    private fun launchTimesUpScreen() {
        val intent = Intent(this, TimesUpActivity::class.java).apply {
            flags = Intent.FLAG_ACTIVITY_NEW_TASK
        }
        startActivity(intent)
    }

    override fun onInterrupt() {}
}
```

> ⚠️ Keep this handler **fast**. No heavy work here — just check balance (one DB read) and fire an intent if needed. Heavy work like deducting balance can be offloaded to a coroutine.

## Phase 5 — Zustand Store

```ts
// store/useTimerStore.ts
import { create } from 'zustand';
import ScreenTime, { AppaceSettings } from '../modules/screen-time';

interface TimerStore {
  balanceSeconds: number;
  windowStartHour: number;
  windowEndHour: number;
  openingBalanceMinutes: number;
  hourlyAccrualMinutes: number;
  trackedApps: string[];
  isWithinWindow: boolean;
  fetchBalance: () => Promise<void>;
  fetchSettings: () => Promise<void>;
  checkWindow: () => Promise<void>;
  setWindowHours: (start: number, end: number) => Promise<void>;
  setOpeningBalance: (mins: number) => Promise<void>;
  setHourlyAccrual: (mins: number) => Promise<void>;
  setTrackedApps: (pkgs: string[]) => Promise<void>;
  // Derived — max possible balance today
  maxDailyMinutes: () => number;
}

export const useTimerStore = create<TimerStore>((set, get) => ({
  balanceSeconds: 0,
  windowStartHour: 6,
  windowEndHour: 24,
  openingBalanceMinutes: 5,
  hourlyAccrualMinutes: 5,
  trackedApps: [],
  isWithinWindow: false,

  fetchBalance: async () => {
    const balance = await ScreenTime.getBalance();
    set({ balanceSeconds: balance });
  },

  fetchSettings: async () => {
    const s = await ScreenTime.getSettings();
    set({
      windowStartHour: s.windowStartHour,
      windowEndHour: s.windowEndHour,
      openingBalanceMinutes: s.openingBalanceMinutes,
      hourlyAccrualMinutes: s.hourlyAccrualMinutes,
    });
  },

  checkWindow: async () => {
    const within = await ScreenTime.isWithinWindow();
    set({ isWithinWindow: within });
  },

  setWindowHours: async (start, end) => {
    await ScreenTime.setWindowHours(start, end);
    set({ windowStartHour: start, windowEndHour: end });
  },

  setOpeningBalance: async (mins) => {
    await ScreenTime.setOpeningBalance(mins);
    set({ openingBalanceMinutes: mins });
  },

  setHourlyAccrual: async (mins) => {
    await ScreenTime.setHourlyAccrual(mins);
    set({ hourlyAccrualMinutes: mins });
  },

  setTrackedApps: async (pkgs) => {
    await ScreenTime.setTrackedApps(pkgs);
    set({ trackedApps: pkgs });
  },

  maxDailyMinutes: () => {
    const { windowStartHour, windowEndHour, openingBalanceMinutes, hourlyAccrualMinutes } = get();
    const hours = windowEndHour - windowStartHour;   // e.g. 24 - 6 = 18
    return openingBalanceMinutes + (hours * hourlyAccrualMinutes);  // e.g. 5 + (18 × 5) = 95
  },
}));
```

## Phase 6 — Edge Cases to Handle

| Scenario | Handling |
|---|---|
| App killed / phone rebooted | BootReceiver restarts ForegroundService; WorkManager reschedules automatically |
| Phone off over midnight | On next `tick()`, `lastResetDate` check catches it — resets balance before granting new day's opening balance |
| WorkManager fires multiple times in one hour | `lastAccrualHour` prevents double accrual — idempotent by design |
| User opens tracked app at 11:59pm with 10 mins | Session is allowed to run; reset applies on *next* app open after midnight |
| User opens tracked app outside window | No enforcement — apps unrestricted outside window |
| User opens tracked app within window, zero balance | Time's Up overlay launched immediately |
| User changes window hours mid-day | New hours apply from next `tick()`; today's `lastResetDate` and `windowOpenGrantedToday` remain valid |
| User changes hourly accrual mid-day | Takes effect from the next hour's drop |
| Accessibility Service killed silently | Detect on app open, show persistent warning on home screen |
| Wrong foreground app detected (system UI) | Filter `com.android.systemui`, `com.android.launcher` and other system packages |
| User uninstalls a tracked app | Filter `trackedApps` list against installed apps on each settings load |

### How the Daily Cycle Works End-to-End

```
5:59am  → outside window, apps unrestricted, tick() does nothing
6:00am  → tick() fires, windowOpenGrantedToday=false → grants 5 min opening balance, sets windowOpenGrantedToday=true
6:14am  → tick() fires, currentHour(6) == lastAccrualHour(6) → does nothing
6:29am  → tick() fires, same → does nothing
7:00am  → tick() fires, currentHour(7) > lastAccrualHour(6) → grants 5 mins silently, sets lastAccrualHour=7
...
11:00pm → tick() fires, grants last 5 mins of the day silently
11:45pm → tick() fires, currentHour(23) == lastAccrualHour(23) → does nothing
12:00am → tick() fires, todayStr != lastResetDate → wipes balance, resets flags
6:00am  → new day begins
```

## Notes for Your IDE Session

- When writing the Kotlin native module, run `npx expo prebuild` first to eject the Android project — you'll need access to the raw `android/` folder
- Use `npx expo run:android` (not Expo Go) since native modules require a development build
- Keep the Accessibility Service logic **synchronous and minimal** — offload anything heavy to a coroutine with `Dispatchers.IO`
- Room DB access must **never** happen on the main thread — always wrap in `withContext(Dispatchers.IO)`
- WorkManager's `PeriodicWorkRequest` minimum interval is 15 minutes on Android — for testing, use 15 min intervals and scale up to 1 hour for production
- Store accrual rate and cap in **SharedPreferences** (not just Room) so the Accessibility Service can read them without a DB query on every event
